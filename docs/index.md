# LongBarcodeQC

*LongBarcodeQC* is a command-line tool meant for processing and analyzing raw long-read sequencing data alongside the synthesis of combinatorially barcoded plasmid libraries. Currently the software is tailored to support Nanopore data, but should work with any fastq input.
