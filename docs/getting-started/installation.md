# Installation

## via Conda

```bash
conda install -c conda-forge LongBarcodeQC
```

## via pip

```bash
pip install LongBarcodeQC 
```

## External requirements

git clone https://github.com/rrwick/Porechop.git
cd Porechop
python3 setup.py install
